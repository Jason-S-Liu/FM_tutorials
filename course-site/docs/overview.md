# 流体力学（1）

本课程面向重庆大学土木工程学院本科生，围绕土木工程中常见的水流、气流、管网与结构绕流问题组织教学。

课程主线为：

```text
基本概念与控制方程 -> 能量方程与量纲分析 -> 管道流 -> 边界层与钝体绕流 -> 土木工程应用
```

## 学习目标

完成课程后，学生应能：

1. 判断连续介质假设、不可压缩假设、无黏/有黏假设的适用边界。
2. 从质量守恒、动量守恒和能量守恒出发，理解连续性方程、Navier-Stokes 方程和 Bernoulli 方程的物理意义。
3. 使用量纲分析构造常见无量纲数，理解 Re、Fr、Eu、St、Cd 在实验与工程缩尺中的作用。
4. 计算典型管道层流、湍流及局部/沿程损失，并能把雷诺数判别与工程管网问题联系起来。
5. 解释平板边界层、转捩、涡量、圆柱/方柱分离、剪切层、尾流和回流区等外流现象。
6. 能读懂简单流场图、压力分布图和尾流结构图，并用流体力学语言进行工程解释。
